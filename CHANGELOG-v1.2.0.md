# v1.2.0 — Static Discovery and Citation Edition

- Generates a complete static article directory from `daily/` on every update.
- Generates one independent HTML page for each public observation record.
- Publishes article titles, dates, summaries, and full text directly in HTML.
- Generates a complete chronological archive, sitemap, RSS feed, robots file, and canonical URLs.
- Adds structured Article and CollectionPage metadata.
- Adds stable citations, GitHub source links, revision history links, immutable version links, and SHA-256 fingerprints.
- Preserves all original observation files, filenames, dates, folders, and Git history.
- Deploys through GitHub Actions without requiring generated pages to be committed to the research repository.

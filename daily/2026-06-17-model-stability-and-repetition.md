# Notes on Stability and Repetition

Over the past month, the current model set has already appeared in public form.

SBF-001, RD-001, and DAF-001 are not new releases.

What changed recently was not the models themselves, but the structure around them.

The model index was simplified.

The relationships between the models became clearer.

The focus gradually shifted from creating models to maintaining continuity.

This raises a different question.

At what point does a model become stable?

Not when it is written.

Not when it is published.

Perhaps when it can repeatedly explain observations across different situations without requiring constant revision.

For now, the task is not to add more models.

The task is to observe whether the existing models remain useful when applied to new observations.
